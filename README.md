## Project Overview

Brass & Beyond is an e-commerce brand offering jewelry, body care, and wellness products. This project involved transforming an existing Shopify storefront into a cohesive, visually engaging shopping experience inspired by 1970s aesthetics, Afrocentric beauty, nature, and cultural expression.

**Developer & Designer:** JeLaya Williamson | Melanin Coded  
**Platform:** Shopify  
**Project Type:** Client E-Commerce Redesign  
**Status:** Launched

## Project Goals

- Establish a distinctive, consistent brand identity.
- Improve storefront navigation and product discovery.
- Organize products into meaningful collections.
- Create a cohesive desktop and mobile shopping experience.
- Improve customer-facing pages and store presentation.
- Customize checkout branding to complement the storefront.

## Design Direction

The redesigned storefront features warm cream backgrounds, chocolate-brown typography, burnt-orange accents, floral illustrations, and richly detailed imagery.

The visual direction combines retro-inspired design with Afrocentric influences to reflect the brand's personality and product offerings.

## Work Completed

- Customized Shopify storefront theme
- Designed homepage hero and promotional sections
- Developed collection presentation and navigation
- Organized product categories and featured merchandise
- Improved product titles and storefront presentation
- Created and customized informational pages
- Updated footer navigation and brand messaging
- Customized checkout appearance
- Reviewed responsive desktop and mobile layouts
- Prepared the redesigned storefront for launch
